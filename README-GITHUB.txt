SIMPLE AAC — GITHUB UPLOAD

This version is arranged specifically for uploading from iPhone/iPad.

IMPORTANT:
Upload ALL files in this folder into the ROOT of your GitHub repository.
There is NO icons folder to create.

Files:
- index.html
- app.js
- styles.css
- sw.js
- manifest.webmanifest
- icon-180.png
- icon-192.png
- icon-512.png

After uploading:
1. Commit the files.
2. GitHub: Settings → Pages.
3. Set Source to Deploy from a branch.
4. Select your main branch and / (root).
5. Save.
6. Open the GitHub Pages URL in Safari.
7. Use Share → Add to Home Screen.

Do not rename the files.
